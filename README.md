## Projeto em destaque

### [CineLista — catálogo de filmes](https://github.com/Noobdf/WS)

Aplicação web com **CRUD completo** para cadastrar, consultar, editar e excluir filmes. Inclui busca por título ou gênero, filtros de assistidos, interface responsiva e persistência em MongoDB.

![Interface do CineLista](https://raw.githubusercontent.com/Noobdf/WS/main/docs/cinelista.png)

**Tecnologias:** Node.js, Express, MongoDB, Mongoose, HTML, CSS e JavaScript.

**Práticas presentes:** validação no servidor, respostas HTTP de erro, configuração por variáveis de ambiente, testes HTTP com MongoDB temporário e fluxo de testes no GitHub Actions.

[Ver código e instruções para executar →](https://github.com/Noobdf/WS#readme)
